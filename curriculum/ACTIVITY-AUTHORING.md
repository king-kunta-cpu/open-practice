# The 50-activity practice studio

These are original authored expansions of the user's 50 exercises. Stable activity numbers preserve a one-to-one mapping. Ten collections contain five activities each; all fifty are independently accessible and are additions to the existing six foundation paths/36 activities.

Each canonical JSON includes a unique rationale, fictional starting input, copy-and-adapt prompt, worked reference, five guided steps, three specific tests, common mistakes, four visual-guide stages, an offline route, reflection and evidence criteria. Timing is an editorial estimate. Independent subject-matter review and learner timing remain pending.

## Important corrections
- Three examples are few-shot, not one-shot. A style blueprint is plausible analysis, not recovery of a hidden original prompt.
- A persona does not confer financial qualifications. Visible expression is not identity or emotion. Pretrained image classification is not custom training; the activity requires learners to state the actual route. Hosted training can need paid resources; a dataset/test-plan route does not claim model training. No local model is automatically downloaded or run by this platform.
- Retired desktop software is not a required dependency. Provider names/links are starting points, not free-tier guarantees, endorsements or promises of unchanged interfaces. Google AI Studio's vision route is classification with a hosted model, not a custom trainer.
- Longer explanations and requests for hidden reasoning do not guarantee accuracy. Ask for concise checkable calculations and verify externally.
- Back-translation does not certify meaning. PDF parsing needs page, unit and scope checks. Two articles may share one original source.
- Simulated interviews/focus groups generate hypotheses, not real participants, subconscious reactions or market evidence. Résumé revisions must remain truthful. Contract review produces questions for a qualified adviser, not legal clearance.
- An image mockup does not establish accessible semantics, usable states or compliant contrast. Calculate contrast from actual colour values; even a passing ratio is not a complete accessibility audit.
- Images/outpainting invent content. Keep source originals, consent, rights and generated-content labels. Use generic licensed synthetic voices rather than unconsented clones.
- A workflow diagram is not an integration; a SQL draft is not an executed query; valid JSON syntax is not a complete schema or a factual check. Regex examples implement a stated limited policy, not universal email validation.

## Build and visual design
`python3 scripts/build-activities.py` creates the 25 KB catalogue, fifty individual JSON details, fifty original editorial SVG covers, fifty original four-stage SVG workflow guides, fifty Markdown handbooks/inputs, ten collection workbooks and ten deterministic practice ZIPs. The hero is explicitly AI-generated editorial art. Workflow guides are labelled illustrations, not provider screenshots. Original fictional CSV and PDF fixtures make representative activities startable without private data.

The foundation builder runs first, then this builder adds ten activity-pack entries, bringing the resource index to 31. Test builds use isolated temporary directories rather than mutating published files mid-test.

## Progress and privacy
Evidence stays in `op-activities` local browser storage until a learner explicitly saves it. Account workspaces use `lab-<stable-id>`, leaving foundation IDs/notes unchanged. Restore is explicit, uses the saved-version baseline, and retains existing conflict protection. Self-review requires a build, test log, reflection and three evidence confirmations. The chosen route distinguishes manual fixtures, design-only work and reported hosted AI runs. None is independently verified assessment or accreditation.

Standalone HTML embeds the guide and complete activity, editable evidence and a JSON round trip. It contains no provider credentials, runtime libraries, network calls or automatic cloud sync. Offline edits persist only after downloading an updated copy. Users must keep secrets out of notes themselves.

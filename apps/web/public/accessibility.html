OPEN PRACTICE / ACCESSIBILITY STATEMENT

Useful access, without a blanket claim.

The aim is readable, keyboard-usable learning that works across screen sizes and has practical low-connectivity alternatives. This is a work in progress, not an independent conformance certificate.

Published 21 October 2026 · current independent pilot

What is implemented

Core pages use semantic headings, labelled controls, visible keyboard focus, native buttons and dialogs, image descriptions and responsive layouts. Carousel controls support keyboard navigation. Reduced-motion preferences are respected. The illustrated guides also provide instructional text outside images.

Reading and offline alternatives

Static activity guides can be read without JavaScript. Markdown handbooks, fictional inputs and offline HTML exports are available. Use the alternate reading site if the main host cannot be reached; account services remain on the main host. Download needed materials before relying on an offline session.

Known limits

No full independent WCAG audit or comprehensive assistive-technology review has been completed. Artwork may contain incidental generated markings; rely on the authored instructions rather than small text inside illustrations. Some interactive features require JavaScript, and external tools may have their own accessibility barriers. A colour-contrast check alone is not an accessibility audit.

Tell us what blocks you

Use the contact page's public issue route with a redacted description: page URL, the task you tried, what happened and, if comfortable, browser and assistive technology. Do not disclose medical information, credentials or private learner work. A dedicated private support channel and guaranteed response time are not currently offered.

Practical navigation

Tab moves through controls; Enter or Space activates native buttons. Arrow keys, Home and End select carousel items. Escape closes a native dialog. Browser zoom and system text settings are supported in the tested layouts, but that is not a guarantee for every device or content combination.

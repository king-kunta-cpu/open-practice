Write your first good prompt

Most poor AI results come from vague requests. A prompt that says who it is for, what you need and how to check it gets better answers from any model.

Do it now

  1. Write a lazy prompt: “Write a post about my shop.”
  2. Now add: who the reader is, what you want them to do, two facts about your shop, the length and the tone.
  3. Add a check: “List any claim I should verify.”
  4. Run both prompts (or use the guided template) and compare.
  5. Save the better prompt — it is now reusable.

Check yourself

Answer in your head first, then open each one.

Name the five parts of a strong prompt.

Role, task, context, format, and checks/constraints.

Why ask the AI to list claims to verify?

It makes uncertain facts visible so you can check them before using the text.

Tip

Keep a “prompts that worked” note. Reusing good prompts saves more time than any trick.

Learn AI from zero — by doing

Ten short lessons, about 2 hours in total. Each one ends with something real: a better prompt, a checked answer, an email sent, a page published.

After the ten lessons

Pick a project path or try any of the 39 free tools. Everything follows the same loop: brief → make → check → improve → ship.

Questions people ask

I have never used AI. Is this for me?

Yes. Lesson one assumes nothing. You only need a phone or computer with a browser.

Do I need to pay for anything?

No. Every lesson uses free tools, and most work without any AI account at all.

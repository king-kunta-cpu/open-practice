PRIVACY / PILOT POLICY · 21 OCTOBER 2026

Your learning. Clear boundaries.

Accounts and saved work

Adult learners can register with a username and password. We store a salted PBKDF2-SHA256 password hash, hashed recovery codes, expiring session records, and workspaces you explicitly save. No email or date of birth is collected. Do not place sensitive information in a username or project.

First-party learning analytics

While signed in, the platform records these named events: lesson opened, lesson completed, checkpoint passed, workspace saved/downloaded, resource downloaded, and news opened. Events contain your account ID, the course/resource identifier, event name, and time. They do not include keystrokes, workspace text, private prompts, or API keys. Event records are normally retained for 90 days, with daily cleanup. No advertising, third-party analytics scripts, fingerprinting, or session replay is installed. Public pages work without an account and no learning events are sent while signed out.

Cloud AI and learner keys

The optional platform tutor uses company-configured inference providers. Practice uses your selected Google AI Studio, Groq, or Cloudflare account. Keys pass through this platform's server for the current request and are sent only to the selected provider; application code does not persist or log them. The key field is cleared after each request and on sign-out. Providers and infrastructure have their own retention, billing, and processing terms. Never submit private data or assume free access is unlimited.

Browser storage and offline files

Local drafts use browser storage. Downloaded HTML and JSON contain your learning content, not API keys, passwords, session cookies, or cloud credentials. Files are not encrypted: keep them private. Download an updated HTML copy after offline edits. Other users of a shared browser may access local notes.

Export, recovery, and deletion

Use the Account menu to export cloud work and learning events, or permanently delete the account after password confirmation. This does not remove local browser copies or files you downloaded. Recovery uses the code shown at account creation; there is no email recovery. Lost passwords without a recovery code cannot be reset by this pilot.

Cookies and infrastructure

Sign-in uses a Secure, HttpOnly, SameSite session cookie, valid up to 30 days. Cloudflare hosts the application and database. Provider/hosting security and operational logs are governed separately. The platform does not promise zero-retention or anonymity.

Operator and pilot limits

This is an independent, non-accredited pilot operated through the linked source repository. Registration is currently limited to adults aged 18+. Questions and issues can be raised through the project issue tracker; do not post private data there. A dedicated private support channel and additional safeguarding are required before opening child accounts.

# 38. Fight corporate fog with concrete verbs

Open Practice / Workplace writing

Estimated time: 35 minutes. Not learner-validated.

Original material: CC BY 4.0. Independent, non-degree and non-accredited.

Rewrite a vague announcement while exposing missing decisions.

## Why this matters

Plain English is not a guarantee of cross-cultural comprehension, but it makes ambiguity easier to see. Keep named owners, actions and deadlines when they exist; ask for them when they do not. Do not invent a plan simply to make the announcement sound decisive.

## Practice input

```text

Original: “We are leveraging synergies to operationalize next-generation deliverables across stakeholder ecosystems.” Known facts: the support and logistics teams will combine weekly issue lists. Tari owns the first combined draft. No deadline is agreed.

```

## Copy-and-adapt prompt

```text

Rewrite the announcement in plain, active language for a reader unfamiliar with the organization. Use only the supplied facts. State the action, owner and missing deadline. Avoid buzzwords and do not invent a benefit, launch date or mandatory process. Add one clarifying question.

```

## Worked reference

“Support and logistics will combine their weekly issue lists. Tari will prepare the first combined draft. We still need to agree when it is due. What date should Tari use?” This is clearer without pretending the work is already implemented.

## Guided activity

1. **Separate slogan from facts.** Underline which parts of the announcement contain no concrete action.

2. **Request a plain rewrite.** Supply the fact ledger so the model does not fill the gaps itself.

3. **Inspect verbs and owners.** Circle who does what and identify every unresolved field.

4. **Read aloud to a partner.** Ask them to repeat the next action without explaining the original jargon.

5. **Refine and keep a question.** Shorten confusing terms while retaining the missing-deadline question.

## Test your result

- [ ] The rewrite names the two teams, Tari and the combined issue-list task.

- [ ] It does not invent a deadline, benefit number or completed implementation.

- [ ] A reader can identify the action and what still needs agreement.

## Common mistakes

- Replacing one set of buzzwords with another.

- Assuming simpler wording authorizes a new plan.

## No-account / offline route

Rewrite the fixture by hand using subject–verb–object sentences and one explicit unresolved question.

Which missing fact became more visible after you removed the jargon?

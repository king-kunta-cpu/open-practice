# 10. The logo iteration loop

Open Practice / Creative production

Estimated time: 45 minutes. Not learner-validated.

Original material: CC BY 4.0. Independent, non-degree and non-accredited.

Translate vague feedback into testable visual constraints.

## Why this matters

A generated mark is a concept, not a trademark-cleared identity or a production-ready vector. Some generators have a separate negative-prompt field; others need plain-language constraints. Judge the output visually either way. Keep a short design brief fixed and improve one failure at a time.

## Before you start

Materials are free. External tools may require an adult account, credits, regional eligibility or a paid plan. Check current terms before using them. Do not paste passwords, API keys, private messages or other people’s personal data. No model runs locally or downloads automatically on this platform.

## Practice input

```text

Fictional café: Ember Cup. Desired mark: a warm, welcoming symbol, readable at 32 pixels, two colours, no letters required. Avoid green, coffee-bean silhouettes, real brands and detailed texture.

```

## Copy-and-adapt prompt

```text

Create one original symbol concept for a fictional café. Use burgundy and warm cream only. No green, no coffee beans, no text, no gradients or tiny decorative details. The symbol must remain distinguishable at 32 pixels. Suggest an alternative motif such as a cup-shaped sunrise without copying an existing logo.

```

## Worked reference

Review record: Version A uses a green leaf and tiny steam lines → fails colour and small-size checks. Revision B uses a two-colour cup/sun outline → passes those checks, but still needs originality/trademark review and vector redrawing.

## Guided activity

1. **Freeze the brief.** Write the audience, two colours, size test and forbidden elements before generating.

2. **Make one concept.** Save the unedited first result. Do not accept a model’s claim that it followed the constraints.

3. **Inspect at small size.** View at 32 and 64 pixels; count colours and look for bean/leaf shapes or accidental letters.

4. **Revise specifically.** Say which visible element must change while preserving the rest of the brief.

5. **Document handoff limits.** Keep the brief, two versions and test table. Note that legal clearance and production vector work remain undone.

## Test your result

- [ ] The final concept visually contains no green, beans or unintended text.

- [ ] A 32-pixel preview remains recognizable without relying on tiny detail.

- [ ] The handoff distinguishes concept development from trademark clearance and production vector delivery.

## Common mistakes

- Believing a negative prompt guarantees exclusion.

- Calling an attractive raster concept a finished brand system.

## Evidence to keep

- **Keep the build**: Save your original input, exact prompt and resulting artifact. The final concept visually contains no green, beans or unintended text.

- **Show what you tested**: Record a pass/fail result and evidence for every check below. A 32-pixel preview remains recognizable without relying on tiny detail.

- **Explain a limitation**: Write what changed after one deliberate revision and name a remaining failure mode. Believing a negative prompt guarantees exclusion.

## No-account / offline route

Sketch two symbol concepts in the supplied brief, colour them with the two allowed colours and run the same small-size check.

## Reflection

Which revision improved function rather than just personal taste?

# 18. Direct a spoken explanation

Open Practice / Creative production

Estimated time: 45 minutes. Not learner-validated.

Original material: CC BY 4.0. Independent, non-degree and non-accredited.

Compare voice delivery while keeping script, consent and meaning constant.

## Why this matters

Voice style affects perceived confidence but does not make the script accurate. Use generic licensed synthetic voices, never an unconsented clone. Write a short verified script, hold its words fixed, and compare intelligibility, pauses and pronunciation. Provider availability and free allowances vary.

## Before you start

Materials are free. External tools may require an adult account, credits, regional eligibility or a paid plan. Check current terms before using them. Do not paste passwords, API keys, private messages or other people’s personal data. No model runs locally or downloads automatically on this platform.

## Practice input

```text

Original script: “A backup is a separate copy you can restore when the original is lost. A copy in the same folder may disappear with the same device. Keep a separate copy, protect access, and test that you can restore it.”

```

## Copy-and-adapt prompt

```text

Read this script in a calm, clear educational style. Keep every word unchanged. Pause at sentence boundaries and pronounce “backup” consistently. Do not add music, claims, names or a cloned person’s voice. [Paste script.]

```

## Worked reference

A review table can rate calm / energetic / storytelling voices on word accuracy, clarity and unwanted additions. A dramatic delivery that changes “may disappear” to “will always disappear” fails even if listeners prefer the sound.

## Guided activity

1. **Check the script.** Verify the meaning first and remove personal information. Time yourself reading it aloud.

2. **Select permitted voices.** Use three generic licensed profiles if available, or two profiles plus your own reading; note the actual route.

3. **Generate separate clips.** Keep the exact script and roughly comparable speed; save settings and tool labels.

4. **Listen and annotate.** Mark mispronunciations, missing words, misleading emphasis and long pauses against the transcript.

5. **Revise the direction.** Change one delivery instruction and compare the new clip; retain an accessible text transcript.

## Test your result

- [ ] All clips use the same script and have a readable transcript.

- [ ] The chosen voice is generic/licensed or your own, with no unconsented identity cloning.

- [ ] Your comparison measures wording and intelligibility separately from personal preference.

## Common mistakes

- Mistaking a confident voice for trustworthy content.

- Using a celebrity or colleague’s voice without permission.

## Evidence to keep

- **Keep the build**: Save your original input, exact prompt and resulting artifact. All clips use the same script and have a readable transcript.

- **Show what you tested**: Record a pass/fail result and evidence for every check below. The chosen voice is generic/licensed or your own, with no unconsented identity cloning.

- **Explain a limitation**: Write what changed after one deliberate revision and name a remaining failure mode. Mistaking a confident voice for trustworthy content.

## No-account / offline route

Record yourself delivering the same script in three styles, or annotate three read-aloud directions without generating audio.

## Reflection

Which delivery changed what a listener might believe even though the words stayed similar?

# 46. Chain a visual brief without losing control

Open Practice / Creative production

Estimated time: 45 minutes. Not learner-validated.

Original material: CC BY 4.0. Independent, non-degree and non-accredited.

Turn a descriptive idea into a concise image brief, then inspect instruction drift.

## Why this matters

More descriptive text can create conflicting priorities. A text model’s elaborate scene is a draft brief, not a command the image generator will obey perfectly. Protect a few non-negotiable elements, reduce decorative overload and compare actual images against a stable checklist. Use original concepts rather than recognizable franchise settings.

## Before you start

Materials are free. External tools may require an adult account, credits, regional eligibility or a paid plan. Check current terms before using them. Do not paste passwords, API keys, private messages or other people’s personal data. No model runs locally or downloads automatically on this platform.

## Practice input

```text

Original scene requirements: one floating garden island, one footbridge, a small waterfall, daylight and open sky. No buildings, people, writing or branded characters. Desired mood: quiet and welcoming.

```

## Copy-and-adapt prompt

```text

Write an image brief of at most 120 words using the supplied requirements. Separate subject, composition, lighting, palette and exclusions. Do not add new objects or a hidden story. Then compress it to 45 words while preserving the same fixed elements.

```

## Worked reference

A verbose brief that adds towers and crowds has drifted from the requirements. The short and long versions should both retain one island, one bridge, a waterfall, daylight and the exclusions. Actual image compliance must be scored separately from prose quality.

## Guided activity

1. **Freeze core elements.** Write the five required elements and exclusions as a scorecard.

2. **Draft the long brief.** Use the text prompt and remove additions not authorized by the original idea.

3. **Create the short brief.** Keep the same requirements with fewer modifiers.

4. **Generate and compare optionally.** Use one image per brief in the same provider/model; record settings and variation limits.

5. **Revise from evidence.** Change the brief because of a visible failure, not merely because a longer sentence sounds richer.

## Test your result

- [ ] Both textual briefs preserve required elements and exclusions without extra objects.

- [ ] The long brief is within 120 words and the short one within 45.

- [ ] If images are generated, their visible compliance is scored separately from the descriptions.

## Common mistakes

- Assuming a dense brief gives more precise control.

- Allowing each stage to add objects until the final scene no longer matches the original task.

## Evidence to keep

- **Keep the build**: Save your original input, exact prompt and resulting artifact. Both textual briefs preserve required elements and exclusions without extra objects.

- **Show what you tested**: Record a pass/fail result and evidence for every check below. The long brief is within 120 words and the short one within 45.

- **Explain a limitation**: Write what changed after one deliberate revision and name a remaining failure mode. Assuming a dense brief gives more precise control.

## No-account / offline route

Write the two briefs and sketch thumbnail compositions, marking which required elements survived.

## Reflection

Which decorative phrase could you remove without losing a meaningful instruction?

# 47. Direct negative space with a measurable brief

Open Practice / Creative production

Estimated time: 40 minutes. Not learner-validated.

Original material: CC BY 4.0. Independent, non-degree and non-accredited.

Use object size and position as composition requirements rather than vague adjectives.

## Why this matters

“Minimalist” can describe style without specifying layout. Define the main object, its approximate image area and where empty space belongs. The goal is not a mathematically exact segmentation model: use a rough grid and disclose estimation limits. A usable composition still needs visual hierarchy and an intentional subject.

## Before you start

Materials are free. External tools may require an adult account, credits, regional eligibility or a paid plan. Check current terms before using them. Do not paste passwords, API keys, private messages or other people’s personal data. No model runs locally or downloads automatically on this platform.

## Practice input

```text

Scene: one plain coffee mug on an off-white background. Mug in the lower-right region; approximately 5–10% of frame area. Keep the upper-left two-thirds open for a future title, but do not generate any text or logo.

```

## Copy-and-adapt prompt

```text

Create one original minimal flat-lay image with a single plain mug in the lower-right. Use soft daylight and a solid warm off-white background. The mug should occupy roughly 5–10% of the full image area. Keep the upper-left two-thirds visually empty. No text, logos, extra props or dramatic texture.

```

## Worked reference

Overlaying a simple 10×10 grid helps estimate occupied area. A mug spanning about 2×3 cells has a bounding area around 6%, though its actual silhouette is smaller. A large shadow or extra spoon may interfere with the intended title space.

## Guided activity

1. **Specify the layout.** Write size, position and empty-region requirements before generating.

2. **Create one image.** Keep the original prompt/settings and the unedited output.

3. **Estimate with a grid.** Approximate the object’s bounding area and note shadow/shape limitations.

4. **Test the empty region.** Place a temporary text box in a separate editor to see whether the intended title area is usable.

5. **Refine the weakest condition.** Adjust scale or positioning language once, retaining both versions for comparison.

## Test your result

- [ ] The output contains exactly one mug and no text or unwanted props.

- [ ] The area estimate and its bounding-box limitation are documented.

- [ ] The upper-left title region is demonstrably usable, not merely described as minimalist.

## Common mistakes

- Treating “minimalist” as a precise placement instruction.

- Claiming exact object-area measurement from a rough visual estimate.

## Evidence to keep

- **Keep the build**: Save your original input, exact prompt and resulting artifact. The output contains exactly one mug and no text or unwanted props.

- **Show what you tested**: Record a pass/fail result and evidence for every check below. The area estimate and its bounding-box limitation are documented.

- **Explain a limitation**: Write what changed after one deliberate revision and name a remaining failure mode. Treating “minimalist” as a precise placement instruction.

## No-account / offline route

Draw the scene on a 10×10 grid and reserve the title region before choosing the mug size.

## Reflection

Did the shadow consume more useful space than the mug itself?

# 48. A three-frame story with continuity

Open Practice / Creative production

Estimated time: 60 minutes. Not learner-validated.

Original material: CC BY 4.0. Independent, non-degree and non-accredited.

Translate a short narrative into consistent visual briefs and inspect change across frames.

## Why this matters

Separate the story’s changing action from its fixed character and setting details. Repeating a style phrase does not guarantee continuity; reference-image support and controls vary by tool. Use an original fictional character, no real likeness, and keep all three frames as separate artifacts with a continuity ledger.

## Before you start

Materials are free. External tools may require an adult account, credits, regional eligibility or a paid plan. Check current terms before using them. Do not paste passwords, API keys, private messages or other people’s personal data. No model runs locally or downloads automatically on this platform.

## Practice input

```text

Original story: A small orange maintenance robot finds a seed on a rooftop. It plants the seed in a cracked blue pot. At sunrise it shelters the first leaf from the wind. Fixed details: round body, one square eye, blue pot, same rooftop; no logos or writing.

```

## Copy-and-adapt prompt

```text

Create three separate frame briefs, one per sentence. For each list fixed character/prop details, action, camera view and light. Use one coherent hand-drawn editorial style. Do not change the robot’s eye, pot colour or rooftop between frames. Do not claim that prompt repetition guarantees visual consistency.

```

## Worked reference

Continuity ledger: robot round/orange/one square eye in all frames; pot blue once introduced; same rooftop edges. The action and time/light may change. A second eye or red pot is a continuity error, not a new story fact.

## Guided activity

1. **Write the three sentences.** Keep the plot simple enough to show one action per frame.

2. **Make a continuity sheet.** Separate permanent character/setting features from allowed changes.

3. **Draft three briefs.** Require fixed details in each brief; avoid copying a known fictional franchise.

4. **Generate or draw separately.** Use a permitted reference workflow if available; otherwise record the lack of identity controls.

5. **Review as a sequence.** Compare all fixed features and note at least one correction before presenting the story.

## Test your result

- [ ] There are three separately described frames with one clear action each.

- [ ] Fixed robot, prop and setting details are checked across the sequence.

- [ ] The report documents continuity failures and actual controls used rather than promising perfect consistency.

## Common mistakes

- Treating style consistency as character consistency.

- Using a real person’s likeness or a recognizable character without permission.

## Evidence to keep

- **Keep the build**: Save your original input, exact prompt and resulting artifact. There are three separately described frames with one clear action each.

- **Show what you tested**: Record a pass/fail result and evidence for every check below. Fixed robot, prop and setting details are checked across the sequence.

- **Explain a limitation**: Write what changed after one deliberate revision and name a remaining failure mode. Treating style consistency as character consistency.

## No-account / offline route

Draw three thumbnail frames from the continuity sheet and have a reader reconstruct the story.

## Reflection

Which small visual inconsistency changed the story’s meaning?

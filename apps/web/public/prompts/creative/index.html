PROMPT LIBRARY · CREATIVE

6 creative prompts to practise with

Copy a prompt, replace the [BRACKETS] with your details, run it in any AI tool, then check the result. Each prompt includes the habit that makes it reliable.

1Story starter

Give me 5 story openings (2 sentences each) about [THEME] set in [PLACE]. Each must start with action and hint at a problem.

Make it reliable: Choose one and write the next paragraph yourself.

2Image brief

Write an image prompt for [SUBJECT]: setting, style, lighting, composition, colours, aspect ratio [RATIO], and a negative prompt. Avoid real people and brands.

Make it reliable: Change one element per attempt.

3Brand name ideas

Suggest 15 names for a [BUSINESS] in [PLACE] that are easy to say, spell and remember. Group by style. Flag any that might clash with famous brands.

Make it reliable: Check domain and social handles before you love a name.

4Song or jingle (lyrics only)

Write lyrics for a 20-second jingle for [BUSINESS], mentioning [BENEFIT], with a simple repeated line. Avoid copying existing songs.

Make it reliable: Read it out loud with a beat.

5Video storyboard

Make a 6-shot storyboard for a 30-second video about [TOPIC]: shot, what we see, what we hear, on-screen text.

Make it reliable: Shoot it on a phone in an afternoon.

6Character builder

Create a character for [STORY]: goal, fear, secret, how they talk, and one contradiction that makes them interesting.

Make it reliable: Contradictions make characters feel real.

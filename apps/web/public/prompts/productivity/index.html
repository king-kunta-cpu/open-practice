PROMPT LIBRARY · PRODUCTIVITY

6 productivity prompts to practise with

Copy a prompt, replace the [BRACKETS] with your details, run it in any AI tool, then check the result. Each prompt includes the habit that makes it reliable.

1Plan my week

Here are my tasks and deadlines: [LIST]. Make a weekly plan with no more than 3 priorities per day, buffer time, and what to drop if a day goes wrong.

Make it reliable: Plan for the day going wrong.

2Email triage

Sort these email subjects into: reply today, delegate, schedule, archive. Give a one-line reason for each.

[SUBJECTS]

Make it reliable: Never paste private email bodies into public tools.

3Checklist maker

Turn this process into a numbered checklist with a check at each step that proves it was done correctly.

[PROCESS]

Make it reliable: Good checklists include “how you know it’s done”.

4Decision helper

I am deciding between [OPTIONS]. Criteria: [CRITERIA]. Build a weighted scoring table, show the maths, and tell me what information would change the result.

Make it reliable: The “what would change it” line is the useful part.

5SOP writer

Write a standard operating procedure for [TASK]: purpose, who, tools, steps, common mistakes, and what to do when something fails.

Make it reliable: Test the SOP with someone new.

6Habit tracker

Design a simple 30-day tracker for [HABIT] with a weekly review question and a rule for missed days.

Make it reliable: A missed-day rule prevents giving up.

PROMPT LIBRARY · CAREER

6 career prompts to practise with

Copy a prompt, replace the [BRACKETS] with your details, run it in any AI tool, then check the result. Each prompt includes the habit that makes it reliable.

1CV bullet upgrade

Rewrite these CV bullets as achievements: action verb + what I did + result with a number where true. Mark any bullet where I need to add a real number.

[BULLETS]

Make it reliable: Never invent numbers — find real ones.

2Interview practice

Act as an interviewer for [ROLE]. Ask me one question at a time, wait for my answer, then give short feedback using STAR (situation, task, action, result).

Make it reliable: Practise out loud, not just in text.

3Job ad decoder

Here is a job ad. List the must-have skills, nice-to-haves, hidden expectations, and 3 questions I should ask the employer.

[AD]

Make it reliable: Match your CV to the must-haves first.

4Networking message

Write a 70-word LinkedIn message to [PERSON/ROLE] at [COMPANY]. Mention [SPECIFIC THING], ask one easy question, no request for a job.

Make it reliable: Specific, small asks get replies.

5Salary research plan

I am negotiating for [ROLE] in [CITY]. List where I can find reliable salary data, what questions to ask, and a script for stating my range politely.

Make it reliable: Verify salary data from at least two sources.

6Portfolio project ideas

Suggest 5 portfolio projects for someone applying to [ROLE] with skills in [SKILLS]. Each must be finishable in a weekend and show a skill employers ask for.

Make it reliable: Ship one; it beats five ideas.

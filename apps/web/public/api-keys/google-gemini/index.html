How to get a free Google Gemini (AI Studio) API key

Generous free tier on Gemini Flash models with a Google account.

Checked 29 October 2026. Free tiers change — confirm the live numbers in the console.

Sign up ↗ Official quickstart ↗ Live limits / pricing ↗

You need
A Google account. No card for the free tier.
Free allowance
Free tier on Flash and Flash-Lite models, with limits set per project and shown in AI Studio (community tracking in October 2026: roughly 10–15 requests per minute and around 1,000–1,500 requests per day on Flash). Pro models are generally paid only.
Best for
Longer documents (very large context window), summaries, multilingual drafts.
Region notes
Only available in countries on Google’s “available regions” list. If AI Studio says it is not available where you are, use Groq or OpenRouter. In the EEA, UK and Switzerland, paid-service data terms apply; elsewhere, free-tier prompts may be used to improve Google products — do not paste private data.
Key looks like
AIza…

Step by step

  1. Go to aistudio.google.com and sign in with your Google account.
  2. Accept the terms. New users get a default Google Cloud project automatically.
  3. Click “Get API key” (or open aistudio.google.com/apikey).
  4. Click “Create API key” and select the default project.
  5. Copy the key — it starts with AIza. Store it privately.
  6. On Open Practice, open Key settings, choose Google Gemini, paste and press “Test key”. Pick a model with “flash” in the name.

Use it on Open Practice

Paste the key into Key settings and press Test key. Then open any free tool and choose “Draft with my AI key”. The key stays in your browser.

If something goes wrong

403 / permission deniedThe API may be unavailable in your country or for this project. Try a new project, or use Groq.
429 with “limit: 0”This project has no free quota for that model. Choose a Flash model or another project.
400 API key not validCopy the full key again from AI Studio.

Keep your key safe

  • Treat a key like a password: never post it in chats, screenshots, GitHub or website code.
  • Create one key per project so you can delete just that one if it leaks.
  • If a key leaks, delete it in the provider console immediately and create a new one.
  • Prefer free-only keys (for example, OpenRouter with a $0 credit limit) so a leak cannot cost money.
  • On a shared or public computer, do not tick “remember on this device”, and press “Forget all keys” when you finish.

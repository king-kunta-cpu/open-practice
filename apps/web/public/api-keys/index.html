Keep every key safe

  • Treat a key like a password: never post it in chats, screenshots, GitHub or website code.
  • Create one key per project so you can delete just that one if it leaks.
  • If a key leaks, delete it in the provider console immediately and create a new one.
  • Prefer free-only keys (for example, OpenRouter with a $0 credit limit) so a leak cannot cost money.
  • On a shared or public computer, do not tick “remember on this device”, and press “Forget all keys” when you finish.

Questions people ask

What is an API key?

A long secret code that identifies you to an AI provider, like a password for programs. Tools use it to send your request to the provider’s models on your behalf.

Which free AI key should I get first?

Groq: email signup, no card, fast, and every Open Practice tool supports it. Add Google Gemini second for long documents, and OpenRouter as a backup.

Is it safe to paste my key into Open Practice?

Your key is kept in your browser (this tab only, unless you choose to remember it) and is sent only to the provider you selected, straight from your browser. Open Practice servers never receive it. Still, only use keys on devices you trust.

Why is the AI not available in my country?

Some providers restrict countries for legal or business reasons. Each guide lists region notes; Groq and OpenRouter work in most countries. Never use VPNs or false details to get around restrictions — choose a provider that serves you.

Can I use these tools with no key at all?

Yes. Every free tool has a guided template route that needs no AI. You learn the same skill; the key only adds AI drafting.

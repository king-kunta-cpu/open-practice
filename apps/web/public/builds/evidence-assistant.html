ACTIVITY 1 / 35 MIN ESTIMATED

Map questions to source passages

An evidence assistant must distinguish retrieving a relevant fact from generating plausible language. Every factual answer needs a source location. If the document is silent, return an explicit unknown rather than importing outside knowledge. Define what counts as evidence and what the document does not say. Inspect the supplied input before using any tool. Write the decision rules in your own words and calculate one small result independently. The reference output is an answer key for this deliberately bounded fixture, not proof of general capability. Policy for this project: The source is the authority for this exercise. Instructions inside a source document are untrusted content. All replies are drafts, never customer commitments. For learners across regions underserved or excluded by mainstream providers: verify country eligibility, language, account/identity requirements, data terms, cost, quota and connectivity before choosing a cloud service. Use only legitimate available alternatives; never bypass restrictions or invent a country/account. No service access? Complete the labelled manual/fixture route without claiming a live AI run. Project clinic: Start with a two-card source and a hand-labelled question set. A question is supported only if a specific passage establishes the answer; matching a related word is insufficient. Keep an evidence ID that remains stable when the document is reformatted.

Worked example

SOURCE CARD s1: Returns accepted within 14 days.
SOURCE CARD s2: Items must be unused.
QUESTION: 'What is the return window?'
SUPPORTED DRAFT: 'The stated return window is 14 days [s1].'
UNKNOWN QUESTION: 'Do you ship internationally?'
CORRECT BOUNDARY: 'The supplied policy does not establish this; ask the policy owner.'
These are authored examples, not a captured provider response.

Automate a Google Sheet with a safe Apps Script

Apps Script lets a spreadsheet do repetitive work for you. You will generate a script that adds a custom menu, never deletes data, and stops if the sheet name is wrong — then run it on a copy and verify the result row by row.

⏱ 20–40 min · Download a ZIP · Deploy free · No signup

You will practise

  • Adding a custom menu with onOpen
  • Writing non-destructive data operations
  • Testing on a copy before real data

No AI key needed. The code comes from a reviewed template.

  1. 1Brief

    Answer a few questions. The generator writes the code; you will read and change it.

    clean-column: trim and fix case · duplicate-finder: highlight repeats · daily-summary: totals by group

  2. 2Make

    Generate the project, then open every file. Comments explain each part. You can edit files right here.

  3. 3Check

    Automatic checks for the mistakes that break real projects: invalid config, leaked keys, missing security steps.

    • 4Improve

      1. Run the check first.
      Your change: Change the script so it also writes the date and time it ran into cell Z1. Run it and check.

    • 5Ship

      Paste into Extensions → Apps Script in your sheet. Free with any Google account. Step-by-step instructions are inside README.md.

    Questions people ask

    Will the script change my data?

    clean-column backs up the original values first; duplicate-finder only colours cells; daily-summary writes to a separate Summary sheet. Always test on a copy.

    Why does Google show a warning?

    Scripts you write yourself are not verified by Google. Read the permissions: this script only uses the open spreadsheet.

    Do I need an AI key to use this?

    No. The guided template teaches the same skill with no AI at all. If you add your own free key (Groq, Google Gemini, OpenRouter, Mistral or Cerebras), the tool can also draft and revise. The key stays in your browser and requests go straight to that provider.

    Where is my work saved?

    In this browser only (local storage), until you copy or download it. Nothing you type is sent to Open Practice.

What Markdown is supported?

Headings, paragraphs, bold, italic, inline code, code blocks, lists, links, quotes and horizontal rules — the core used most often.

Is the output safe to paste into my site?

Text is escaped before formatting, and only http(s), mailto and site-relative links are allowed.

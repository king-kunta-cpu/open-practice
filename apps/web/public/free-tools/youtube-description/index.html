Write a YouTube description with chapters and links

YouTube shows only the first lines of a description before “more”, and chapters need a specific timestamp format. You will write a summary that front-loads the value, real chapters starting at 0:00, and links — then check the format automatically.

    Pro moves
    • Chapters need at least three timestamps, starting at 0:00.
    • Write for the viewer, not the algorithm.
    • Pin a comment with the most important link.
    Questions people ask
    How do YouTube chapters work?
    Add a list of timestamps starting at 0:00 in the description, with at least three chapters, each at least 10 seconds long. YouTube turns them into chapters automatically.
    Do hashtags help on YouTube?
    A few relevant hashtags can help discovery. YouTube may ignore hashtags if there are too many.
    Do I need an AI key to use this?
    No. The guided template teaches the same skill with no AI at all. If you add your own free key (Groq, Google Gemini, OpenRouter, Mistral or Cerebras), the tool can also draft and revise. The key stays in your browser and requests go straight to that provider.

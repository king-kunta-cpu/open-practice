Write a job description that attracts the right people

Long wish-lists scare off good candidates. You will define what the person must achieve in 90 days, separate must-haves from nice-to-haves, state pay and location, and run inclusive-language checks.

  • Using inclusive, plain language

    Pro moves
    • Outcomes attract doers; duty lists attract box-tickers.
    • Showing pay increases relevant applications.
    • Ask a current employee to read it.
    Questions people ask
    How long should a job description be?
    Around 250–400 words is enough for most roles: outcomes, real requirements, pay and how to apply.
    Should I include salary?
    Yes, where you can. Many candidates skip ads without pay, and in some places pay transparency is required by law.
    Do I need an AI key to use this?
    No. The guided template teaches the same skill with no AI at all. If you add your own free key (Groq, Google Gemini, OpenRouter, Mistral or Cerebras), the tool can also draft and revise. The key stays in your browser and requests go straight to that provider.
    Where is my work saved?
    In this browser only (local storage), until you copy or download it. Nothing you type is sent to Open Practice.

Do not have a key?
Follow a 5-minute guide: Groq (recommended), Google Gemini, OpenRouter, Mistral. Or skip it — every tool has a guided template that works without AI.
Safety
  • Treat a key like a password: never post it in chats, screenshots, GitHub or website code.
  • Create one key per project so you can delete just that one if it leaks.
  • If a key leaks, delete it in the provider console immediately and create a new one.
  • Prefer free-only keys (for example, OpenRouter with a $0 credit limit) so a leak cannot cost money.
  • On a shared or public computer, do not tick “remember on this device”, and press “Forget all keys” when you finish.

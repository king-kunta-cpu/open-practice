OPEN PRACTICE / HELP & FREQUENTLY ASKED QUESTIONS

Keep your work. Know the boundaries.

A practical guide to accounts, saving, downloads and provider access. Start with fictional inputs and keep an independent copy of important work.

Published 21 October 2026 · current independent pilot

Do I need an account or a paid AI plan?

No account is needed to read materials or download public resources. Some optional hosted tools require their own account, key, credits or payment. A free chat interface is not automatically a free API. Each activity explains a manual, fixture or design-only alternative where applicable.

Where is my work saved?

Browser saving stays on that device/profile. Save to account and Load account copy are explicit actions; they are not an automatic background sync. The dashboard shows account work and local drafts separately. If cloud loading fails, do not overwrite a known saved copy until you have exported the work you want to retain.

How do I work offline?

Download the relevant handbook, input and practice pack, or export an editable standalone HTML workspace. After editing an offline HTML file, download its updated copy using the file's save control. Offline exports contain your notes, not provider keys or sign-in credentials. Keep them private because they are not encrypted.

How does sign-in recovery work?

Accounts use a username and password, not email. Keep the recovery code shown at registration. Without the password or that code, the pilot cannot reset access. The Account menu lets you replace the recovery code and revoke other sessions. Never include a recovery code in a public support request.

Does completing a path earn a qualification?

No. This is independent, non-accredited learning. Completion and self-review records are self-reported practice, not verified mastery, a certificate or a professional credential. Keep actual artifacts, tests and limitations rather than treating a progress marker as proof.

What if the page will not load or a search changes by itself?

Use the alternate reading site for guides and downloads if the main host fails. Report the exact connection error without bypassing warnings. Catalogue filtering should only follow your own search input; report any remaining password-manager interference with browser/extension details and a redacted screenshot, not your password or account export.

What if a provider does not serve my region?

Check its current country, identity, account, language, data and billing requirements before using it. Choose a legitimate supported alternative if available, or use the labelled manual/fixture route. Do not use false residency, borrowed accounts or restriction bypasses. A fixture result is not a live AI run. Full readable build guides are also available at /builds/index.html; hosted notebooks require their own legitimate account access.

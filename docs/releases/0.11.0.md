# Open Practice 0.11.0 — learn by doing, everywhere

**Library**
- Merged overlapping courses: 36 build paths → 20, now 200 hands-on activities. Absorbed courses become modules inside their primary path.
- Learner work is preserved. A one-time browser migration remaps done steps, notes and quiz answers, keeps a backup in `op-progress-premerge`, and never deletes anything. The server accepts old course ids, and old build, handbook and pack links redirect (301).
- Counts on the home and about pages are now stamped from `courses.json` at build time, so they cannot drift.

**Free tools (39)**
- Writing, social, business, developer, AI and app-builder tools. Each follows the same steps: brief, make, check, improve, ship.
- Bring your own key (Groq, Gemini, OpenRouter, Mistral, Cerebras): the key stays in the browser and requests go straight to the provider. Without a key, a guided template with blanks is used and no live AI runs. Learner tools never use the platform's key.
- The six kids' tools are template-only by design: no AI, no prompt and no key field.

**New sections**
- `/academy/`: 20 paths grouped by goal.
- `/learn/`: 10 beginner lessons, 10 large-print lessons and 6 helpers for seniors, plus kids' tools. Each lesson has an "I did this" tick.
- `/api-keys/`: step-by-step free key guides.
- `/glossary/`: 100 terms, each with an example and a try-it link.
- `/prompts/`: 60 prompts in 10 categories.
- `/ai-tools/`: 36 tools, with qualitative free-plan notes and no prices to go stale.
- `/llms/`: 12 model families.
- `/compare/`: 6 test-it-yourself protocols with a scoring table.
- `/use-cases/` (12) and `/tutorials/` (12).
- `/tool-finder/` quiz, `/community/`, `/settings/` and a branded 404.

**Search and sharing**
- Structured data on every page: Course, HowTo, LearningResource, DefinedTerm, FAQ and Breadcrumb.
- `sitemap.xml`, `robots.txt`, `llms.txt` and a 1200×630 share card.

Verification: 97 Node tests, reproducible asset build, 23k internal links checked with 0 broken, a credential-pattern scan, and browser checks of the merge migration, tool flows, the no-AI kids' tools, the finder quiz, lesson ticks and large print (20px minimum). Production verification follows deployment.

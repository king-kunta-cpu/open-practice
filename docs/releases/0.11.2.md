# Open Practice 0.11.2: community in two halves, social icons on Contact

**Community (`/community/`)**
- The page is split lengthwise. Left: the existing content (starter challenge, facilitator kit, improve the
  lessons, ship something this week, community guidelines). Right: a "Join a free community" panel with large
  buttons for **Whop, Discord, Telegram and Facebook**, where the free communities live. The panel stays in view
  while scrolling on desktop and stacks below the content on phones.
- Every existing link on the page was checked and works.

**Contact (`/contact.html`)**
- New "Find Open Practice on social media" section with icons for Whop, Discord, Telegram, Facebook, X, LinkedIn,
  YouTube, Instagram, TikTok, Threads, Bluesky, Reddit and GitHub.

**One place for every link: `curriculum/social-links.json`**
- Paste a full `https://` link into a platform's `url` and rebuild: the button and icon switch on everywhere.
- An empty `url` renders as a greyed, non-clickable "Opening soon", never a dead link. The build refuses a link
  whose host isn't that platform's (e.g. a Discord button pointing at another site).
- Icons: Simple Icons (CC0); the Whop mark is drawn in the project.

Tests: 103/103.

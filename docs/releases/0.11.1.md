# Open Practice 0.11.1: one Tools menu, Sign-up buttons, a cover for every tool

**Navigation**
- "Tools ▾" and "Free Tools" are now one **Tools ▾** menu. The top link opens the 39 free tools; the dropdown
  starts with "39 free tools", then the tool field desk, AI tools directory, LLM guide, comparisons, tool finder
  quiz and prompt library.

**API keys**
- Every provider row in `/api-keys/` has a real **Sign up ↗** button (opens in a new tab, `rel="noopener nofollow"`,
  with an accessible label naming the provider). Each provider guide's main link is the same button.

**Covers**
- Every tool gets its own original illustrated cover (`scripts/hub/covers.py`), shown on its card in
  `/free-tools/`, in its page hero, and as its own 1200×630 share image instead of the site-wide card.
- No artwork is ever shared: `scripts/prepare-cover-art.py` refuses an illustration that matches one already
  prepared, and `test/covers-nav-keys.test.mjs` checks that no two tools or library items share art.
- This release ships the first 10 covers (all app builders). The other 29 tools, the 9 free-library items
  (which currently borrow course covers) and the info pages that reuse course art follow in 0.11.2. Until then
  those tools keep their emoji card; none borrows another's image.

**Mail**
- Outreach SMTP credentials now point at the shared Gmail app-password box (see `docs/acquisition-operations.md`).
  `OUTREACH_SEND_ENABLED` stays `false` until `POST /api/outreach/test-sender` passes with the operator key.

Tests: 100/100.

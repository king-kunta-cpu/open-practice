# Release 0.10.0 — original project expansion

## User-authorised scope

- Build all 30 strong-fit topic inputs as original projects.
- Embed all 11 merge/support inputs, without inflating the course count.
- Publish none of the 27 conditional or 6 held inputs as courses.
- Serve people across underserved/excluded regions, not one country.
- Preserve the working account, offline, illustrated-cover and search behaviour; deploy and push only after checks.

## Delivered content

36 paths (six preserved plus thirty new), 216 path activities, 50 preserved standalone activities, 266 total activities, 108 self-check questions, 36 capstone rubrics and 91 library resources. The new courses add 180 guided activities, 30 hosted notebooks, runnable synthetic references and answer keys, plus original Make Mula discovery/access/offer/handoff worksheets. Thirty distinct existing original illustrations are reused for new covers; no claim of thirty new paintings is made.

Course source, public topic locators, original authoring profiles, supporting-lesson map and exclusions are version controlled. Every source topic number can be traced through `curriculum/expansion/scope.json`. The external catalogue informed topic choice only: public access was not treated as permission to copy lessons, assignments, certificates or illustrations.

## Verification boundary

Automated checks cover content structure, exact topic scope, supporting input placement, reference fixtures, notebooks, binary packs, readable guides, local/cloud saving, offline export, account cleanup, search guards, artwork decoding and responsive layouts. Actual external provider availability, professional competence, typical income and independent learner outcomes are not established. Course timing and self-review remain unvalidated estimates and learner reports.

## Production safety

No new database namespace, selector, company AI key, schema or required runtime component. Same-Worker assets and existing bindings/secrets are retained by the guarded deployment script. New readable guides are also included in the labelled reading/download fallback, which does not run account APIs or analytics.

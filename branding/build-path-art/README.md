# Illustrated foundation build paths

Six distinct original AI-generated editorial illustrations created for the six foundation paths on 21 October 2026. Not stock photographs, provider screenshots or measured model results. Each source is a separately generated composition, not a recoloured template.

- prompt: questions, source cards and research verification
- replies: shopkeeper reviewing assisted customer correspondence
- sheets: messy receipts transformed into ordered data
- web: a human constructing a tangible website model
- automation: envelope workflow with review gate and safety stop
- cloud: API plumbing, authentication and capacity

Compressed WebP sources are assembled with human-authored titles, labels and accessible descriptions by `scripts/build-path-covers.py`. Public SVGs embed the artwork and have no external dependencies. Source learning content remains unchanged.
